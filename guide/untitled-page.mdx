# Renchi AI

Renchi AI is an inbound voice AI agent platform designed for HVAC, plumbing, and home services businesses. Your AI voice agent handles incoming customer calls 24/7 - diagnosing issues, providing quotes, booking appointments, and escalating emergencies.

## What Renchi AI Does

## How It Works

```
┌─────────────────────────────────────────────────────────────────┐
│                    INBOUND CALL FLOW                            │
├─────────────────────────────────────────────────────────────────┤
│  Customer Call → Twilio/ElevenLabs → AI Voice Agent             │
│                                            ↓                     │
│                              [Natural conversation]              │
│                              [Problem diagnosis]                 │
│                              [Quote & booking]                   │
│                                            ↓                     │
│                        ┌─────────┬─────────┬─────────┐          │
│                        │ Booked  │Transfer │Voicemail│          │
│                        └─────────┴─────────┴─────────┘          │
├─────────────────────────────────────────────────────────────────┤
│                    BACKEND PROCESSING                           │
│  Transcript → Customer Record → CRM Sync → Team Notification    │
└─────────────────────────────────────────────────────────────────┘
```

## Key Features

### Voice Agents
Create multiple AI agents with different personalities, phone numbers, and configurations. Each agent can handle specific types of calls or serve different business locations.

### Conversation Intelligence
Every call is transcribed, analyzed, and summarized. The AI extracts customer details, problem categories, urgency levels, and recommended actions.

### Customer Management
Build a database of customers with call history, booking records, and internal notes. Link calls to existing customers automatically by phone number.

### Action Inbox
Follow-up items (callbacks, quotes, complex issues) land in your team's inbox for human attention. Prioritized by urgency with quick-action buttons.

### Integrations
Connect to your existing tools:
- **ElevenLabs** - Powers the AI voice engine
- **Twilio** - Phone number management
- **Google Calendar** - Appointment scheduling
- **HubSpot / Salesforce** - CRM synchronization
- **Microsoft Teams** - Agent presence and handoffs
